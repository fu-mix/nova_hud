# N.O.V.A. HUD

Iron Man風のHUD（ヘッドアップディスプレイ）をデスクトップに表示するアプリケーションです。
スペースキーの長押しでスキャンエフェクトが発動し、ターゲット情報を表示します。

Electronを使ってデスクトップアプリとして起動するため、背景は透過し、常時最前面で表示されます。

## 🚀 起動方法（初回セットアップ）

### ステップ1: Node.js をインストール

[https://nodejs.org/ja](https://nodejs.org/ja) からLTS版をダウンロードしてインストールしてください。

インストール後、ターミナル（または「コマンドプロンプト」「PowerShell」）で確認:

```bash
node -v
npm -v
```

両方ともバージョン番号が表示されればOKです。

### ステップ2: Electron をインストール

ターミナルで、cloneしたフォルダに移動して、以下を実行:

**Macの場合:**
```bash
cd ~/nova_hudフォルダのパス
npm install
```

**Windowsの場合:**
```bash
cd C:\nova_hudフォルダのパス
npm install
```

完了すると、`node_modules` フォルダと `package-lock.json` ファイルが自動生成されます。
（時間がかかる場合があります）

### ステップ3: 起動

```bash
npm start
```

デスクトップ上にHUDが表示されたら成功です！

## 🎮 操作方法

| 操作 | 動作 |
|---|---|
| **スペースキーを長押し**（約1.6秒） | スキャン開始 |
| **スペースキーを1回押す**（結果パネルが開いている時） | 結果パネル（モーダル）を閉じる |
| マウスを動かす | ヘッドトラッキング風にHUDが微妙に傾く |
| 右上の小さな四角ボタン | アプリを最小化（タスクバー/Dockに格納） |
| **ESCキー** | アプリを終了 |

### スキャンの流れ

1. **スペースキー**を長押し
2. 画面中央に金色のリングが集中して「GO!」と表示されたらスキャン開始
3. スキャンラインが左から右に流れ、ターゲットを検出
4. スキャン完了後、結果パネルが下からスライドアップ
5. 右下の関連情報パネルにもタスクが表示される
6. **スペースキー**または **✕ CLOSE** で結果パネルを閉じる
7. 右下のタスク一覧は次回のスキャンまで表示されたまま残る
8. 再度スペース長押しで何度でもスキャン可能

## 🖱 最小化ボタン

画面右上の角に、小さく目立たない最小化ボタンがあります（HUDのフレーム装飾に擬態しています）。
マウスを近づけると光ります。クリックでアプリが最小化されます。

タスクバー（Windows）または Dock（Mac）のアイコンをクリックすると復元できます。

## 💡 トラブルシューティング

### Q: `npm install` でエラーが出る

**A**: Node.jsのインストールが正しく完了しているか、`node -v` `npm -v` で確認してください。
インストール直後はターミナルを一度閉じて開き直すと反映されます。

### Q: 起動するとウィンドウは出るが、HUDの背景が完全に透明にならない（黒い背景が見える）

**A**: 一部の環境（Windowsの一部設定、Linuxの一部のWindow Manager）では完全な透過がサポートされていません。
その場合は `main.js` で `transparent: false` に変更してご利用ください。

### Q: スペースキーを押してもスキャンが始まらない

**A**: 以下を確認してください:

- アプリのウィンドウにフォーカスが当たっているか（一度HUDの上をクリック）
- スペースキーを離さずに約1.6秒押し続ける必要があります
- 結果パネルが開いている状態でスペースを押すと「閉じる」動作になります

### Q: ESCで終了するとクラッシュする

**A**: 最新の `main.js` では `app.quit()` で安全に終了するよう修正済みです。
古い `main.js` を使っている場合は、リポジトリの最新版に差し替えてください。

### Q: ウィンドウのサイズや位置を変えたい

**A**: `main.js` の `width: 1600, height: 900` の数値を変更してください。
位置を指定したい場合は `x: 100, y: 100` のような行を追加できます。

### Q: 常に最前面表示が邪魔

**A**: `main.js` の `alwaysOnTop: true` を `false` に変更してください。

### Q: クリックしても後ろのアプリにフォーカスが移ってしまう

**A**: Electron経由で起動していれば発生しません。
ブラウザで `nova_hud.html` を直接開いていないか確認してください。必ず `npm start` で起動します。

## 🎨 カスタマイズ

`nova_hud.html` 冒頭の `:root` ブロックで色をカスタマイズできます:

```css
:root {
  --hud-cyan: #4ddbff;          /* メインのシアン色 */
  --hud-gold: #ffb84d;          /* アクセントの金色 */
  --hud-red: #ff3b3b;           /* 警告色 */
}
```

スキャンの長押し時間を変えたい場合は、`nova_hud.html` 内の以下の値を変更してください:

```javascript
const HOLD_MS = 1600;   // ms needed to hold（長押し時間）
```

スキャンライン全体の通過時間を変えたい場合:

```javascript
const SCAN_MS = 4200;  // total left → right time（スキャン総時間）
```
