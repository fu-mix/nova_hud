# N.O.V.A. HUD

Iron Man風のHUD（ヘッドアップディスプレイ）をデスクトップに表示するアプリケーションです。
画面の上半分を長押しすると、スキャンエフェクトが発動し、ターゲット情報を表示します。

Electronを使ってデスクトップアプリとして起動するため、ブラウザを切り替えても背景に消えず、常時最前面表示が可能です。

---

## 📦 ファイル構成

リポジトリには以下のファイルが含まれています:

```
nova_hud/
├── nova_hud.html         ← HUDの本体
├── main.js               ← Electronのウィンドウ設定
├── package.json          ← Electronの依存ファイル
├── README.md             ← このファイル
└── sounds/               ← 任意（音声ファイルを使う場合）
    └── scan_complete.mp3
```

## 🚀 起動方法（初回セットアップ）

### ステップ1: Node.js をインストール

[https://nodejs.org/ja](https://nodejs.org/ja) からLTS版をダウンロードしてインストールしてください。

インストール後、ターミナル（または「コマンドプロンプト」「PowerShell」）で確認:

```bash
node -v
npm -v
```

両方ともバージョン番号が表示されればOKです。

### ステップ2: Electron をインストール

ターミナルで、cloneしたフォルダに移動して、以下を実行:

**Macの場合:**
```bash
cd ~/nova_hudフォルダのパス
npm install
```

**Windowsの場合:**
```bash
cd C:\nova_hudフォルダのパス
npm install
```

完了すると、`node_modules` フォルダと `package-lock.json` ファイルが自動生成されます。
（時間がかかる場合があります）

### ステップ3: 起動

```bash
npm start
```

デスクトップ上にHUDが表示されたら成功です！

## 🎮 操作方法

| 操作 | 動作 |
|---|---|
| **画面の上半分を長押し**（約1.6秒） | スキャン開始 |
| マウスを動かす | ヘッドトラッキング風にHUDが微妙に傾く |
| 🔊 / MUTEDボタン（上部バー右端） | 音声のオン/オフ切替 |
| ✕ CLOSE ボタン（結果パネル右上） | スキャン結果を閉じる |
| **ESCキー** | アプリを終了 |

### スキャンの流れ

1. 画面の上半分（空のエリア）でマウスを**長押し**
2. 金色のリングが集中して「GO!」と表示されたらスキャン開始
3. スキャンラインが左から右に流れ、ターゲットを検出
4. スキャン完了後、結果パネルが下からスライドアップ
5. 右下の関連情報パネルにもタスクが表示される
6. ✕ CLOSE で閉じると、再度スキャン可能

## 🔊 音声機能について

スキャン完了時に**録音済み音声ファイル**を再生できます。

### セットアップ

#### 1. 音声ファイルを準備

- **ファイル名**: `scan_complete.mp3`
- **ファイル形式**: mp3（推奨）
- **長さ**: 5〜15秒程度

**音声内容の例:**
> 「解析が完了しました。対象は富士通デザインセンター長、宇田哲也氏。エンジニア出身でありながら49歳でデザイン組織のトップに就任し、約200名のメンバーを率いてデザイン経営とDXを推進しています。」

#### 2. フォルダに配置

`nova_hud.html` と同じ場所にある `sounds` フォルダの中にmp3ファイルを置いてください。
（`sounds` フォルダがない場合は作成してください）

```
nova_hud/
├── nova_hud.html
├── main.js
├── package.json
└── sounds/
    └── scan_complete.mp3   ← ここに配置
```

Electronで起動した場合、ローカルサーバーなしで音声ファイルが自動的に再生されます。

---

## 🎤 音声ファイルがない場合

音声ファイルが用意できなくても、自動的にOS内蔵の**TTS（音声読み上げ）**にフォールバックします。

- Mac → Kyoko / Otoya などの音声
- Windows → Haruka / Ichiro などの音声

が自動的に使われます。

## 💡 トラブルシューティング

### Q: `npm install` でエラーが出る

**A**: Node.jsのインストールが正しく完了しているか、`node -v` `npm -v` で確認してください。
インストール直後はターミナルを一度閉じて開き直すと反映されます。

### Q: 起動するとウィンドウは出るが、HUDの背景が完全に透明にならない（黒い背景が見える）

**A**: 一部の環境（Windowsの一部設定、Linuxの一部のWindow Manager）では完全な透過がサポートされていません。
その場合は `main.js` で `transparent: false` に変更してご利用ください。

### Q: 音声が鳴らない

**A**: 以下を順に確認:

1. 上部バー右端の🔊ボタンが「MUTED」になっていないか
2. `sounds/scan_complete.mp3` のファイル名・パスが完全一致しているか
3. 一度画面をクリックしてから試す（音声再生にはユーザー操作が必要）

### Q: 長押ししてもスキャンが始まらない

**A**: 画面の**上半分**（上の55%）をクリックしてください。下半分は反応しません。
マウスのボタンを離さずに、約1.6秒押し続ける必要があります。

### Q: ウィンドウを終了したい

**A**: **ESCキー**を押すとアプリが終了します。

### Q: ウィンドウのサイズや位置を変えたい

**A**: `main.js` の `width: 1600, height: 900` の数値を変更してください。
位置を指定したい場合は `x: 100, y: 100` のような行を追加できます。

### Q: 常に最前面表示が邪魔

**A**: `main.js` の `alwaysOnTop: true` を `false` に変更してください。

## 🎨 カスタマイズ

`nova_hud.html` 冒頭の `:root` ブロックで色をカスタマイズできます:

```css
:root {
  --hud-cyan: #4ddbff;          /* メインのシアン色 */
  --hud-gold: #ffb84d;          /* アクセントの金色 */
  --hud-red: #ff3b3b;           /* 警告色 */
}
```
